# TP 1 : Mise en place de JPA et Hibernate avec H2

## 1. But du TP

Ce laboratoire a pour objectif d'implémenter une solution de persistance de données en Java. Il s'agit de relier une application à une base de données H2 fonctionnant en mémoire, tout en utilisant le framework Hibernate.

Les étapes clés abordées dans ce projet sont :
- L'initialisation d'un projet géré par Maven.
- Le paramétrage de la connexion H2 et du dialecte Hibernate (`persistence.xml`).
- La modélisation d'une classe persistante annotée `@Entity` (Classe `Produit`).
- La sauvegarde d'enregistrements en base via l'`EntityManager`.
- L'interrogation de la base de données (sélection globale et ciblage par identifiant).

## 2. Stack Technique

Voici les outils et versions utilisés pour réaliser ce projet :
- **Langage** : Java (JDK 17)
- **Gestionnaire de dépendances** : Apache Maven
- **Spécification** : Jakarta Persistence API (JPA 2.2)
- **Framework ORM** : Hibernate Core (5.6.5.Final)
- **Base de données** : H2 Database (2.1.214)
- **Environnement de développement** : IntelliJ IDEA

## 3. Traces d'Exécution et Explications

### Création automatique de la table
Dès le lancement, Hibernate analyse l'entité `Produit` et génère la structure SQL correspondante grâce à l'option `update` définie dans la configuration.

```sql
Hibernate: 
    create table Produit (
       id bigint generated by default as identity,
        nom varchar(255),
        prix numeric(19,2),
        primary key (id)
    )
```

### Ajout des données en base
Une transaction est ouverte pour sauvegarder trois produits en mémoire. Hibernate traduit la méthode `.persist()` en requêtes SQL `INSERT`.

```text
Hibernate: 
    insert into Produit (id, nom, prix) values (default, ?, ?)
Hibernate: 
    insert into Produit (id, nom, prix) values (default, ?, ?)
Hibernate: 
    insert into Produit (id, nom, prix) values (default, ?, ?)

Produits insérés avec succès !
```

### Récupération et Affichage
En utilisant une requête JPQL (`SELECT p FROM Produit p`), l'application récupère la liste complète des articles qui viennent d'être stockés.

```text
Hibernate: 
    select produit0_.id as id1_0_, produit0_.nom as nom2_0_, produit0_.prix as prix3_0_ from Produit produit0_

Liste des produits :
Produit{id=1, nom='Laptop', prix=999.99}
Produit{id=2, nom='Smartphone', prix=499.99}
Produit{id=3, nom='Tablette', prix=299.99}
```

### Recherche ciblée
La méthode `.find()` permet d'isoler directement un produit spécifique en interrogeant sa clé primaire (dans cet exemple, l'ID n°2).

```text
Recherche du produit avec ID=2 :
Produit{id=2, nom='Smartphone', prix=499.99}
```
